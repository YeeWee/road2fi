  <action>
    Update app/globals.css @theme block to reference the actual CSS variable from next/font:
    ```css
    @import "tailwindcss";

    @theme {
      --font-sans: var(--font-sans);
      --font-mono: ui-monospace, "Cascadia Code", "Source Code Pro", Menlo, Consolas, "DejaVu Sans Mono", monospace;
    }
    ```

    How this works:
    - `--font-sans: var(--font-sans)` — Tailwind's `--font-sans` token references the CSS custom property `--font-sans` set by next/font on the <body> element. When `font-sans` utility is used, it resolves to the Inter font family.
    - `--font-mono` — System monospace font stack as fallback (no Google Font needed for mono).
    - This eliminates the placeholder from Plan 02 with the actual working configuration.

    Important: The Tailwind v4 `@theme` block uses CSS custom properties. The `--font-sans` on the left is the Tailwind design token. The `var(--font-sans)` on the right references the CSS variable that next/font sets on the <body>. This double-reference pattern is how Tailwind v4 integrates with next/font.
