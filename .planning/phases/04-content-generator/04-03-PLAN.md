  <action>
    Create `lib/scraper.ts` with the following structure:

    **Imports:**
    ```typescript
    import * as cheerio from 'cheerio'
    import { YouTubeTranscript } from 'youtube-transcript'
    import { detectUrlType } from './url-utils'
    ```

    **Main exported function `scrapeContent(url: string)`**:
    1. Call `detectUrlType(url)`. If `'invalid'`, throw `new Error('Invalid URL')`
    2. If `'youtube'`, call `scrapeYouTube(url)` and return result
    3. If `'article'`, call `scrapeArticle(url)` and return result

    **`scrapeYouTube(url: string)`**:
    - Extract video ID with regex: `/(?:youtube\.com\/(?:watch\?.*v=|embed\/|shorts\/)|youtu\.be\/)([a-zA-Z0-9_-]{11})/`
    - If no match, throw `new Error('Invalid YouTube URL')`
    - Call `YouTubeTranscript.fetchTranscript(videoId)` to get transcript array
    - Join transcript: `transcript.map(e => e.text).join(' ')`
    - Get metadata via oEmbed: `fetch('https://www.youtube.com/oembed?url=' + encodeURIComponent(url) + '&format=json').then(r => r.json())`
    - Return: `{ title: oembed.title || '', content: text.slice(0, 8000), thumbnail: oembed.thumbnail_url || '' }`
    - If transcript fails (catch block): fall back to oEmbed only — return `{ title: oembed.title, content: '', thumbnail: oembed.thumbnail_url }` with a comment noting transcript was unavailable

    **`scrapeArticle(url: string)`**:
    - `fetch(url)` to get HTML text
    - `const $ = cheerio.load(html)`
    - Remove noise: `$('script, style, nav, header, footer, aside, iframe, noscript').remove()`
    - Extract title: `$('title').text() || $('h1').first().text() || 'Untitled'`
    - Extract content: `$('article, main, .content, .post, #content').text() || $('body').text()`
    - Extract thumbnail (priority order):
      1. `$('meta[property="og:image"]').attr('content')`
      2. `$('meta[name="twitter:image"]').attr('content')`
      3. `$('img').first().attr('src')`
    - Return: `{ title, content: content.trim().slice(0, 8000), thumbnail: thumbnail || '' }`
  </action>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| scrapeContent → external URLs | Server fetches user-supplied URLs — SSRF risk (mitigated by isValidUrl in url-utils.ts) |
| generator.ts → OpenAI API | API key stored in process.env, never exposed to client |
| LLM response → file content | Generated content from LLM trusted but should be validated as JSON |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-07 | Spoofing | scrapeContent() fetch | mitigate | Caller (server action) must validate URL with isValidUrl() from url-utils.ts before calling scrapeContent() |
| T-04-08 | Information Disclosure | generator.ts OPENAI_API_KEY | mitigate | API key read from process.env only; generator.ts is server-only module, never imported by client components |
| T-04-09 | Tampering | LLM JSON response parsing | mitigate | Wrap JSON.parse in try/catch with fallback; response_format: json_object enforces structure from API side |
| T-04-10 | Tampering | scrapeContent content cap | mitigate | Content truncated to 8000 chars with .slice(0, 8000) to prevent token overflow in LLM call |
</threat_model>
